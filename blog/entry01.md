## Content
For my SEP11 freedom project i've been tinkering with different tools for a few weeks. I decided to choose [Kaboom](https://kaboomjs.com/) because Kaboom has many built in features that makes it easier to create a game. My idea for my SEP11 freedom project is to create a jump and running game where the player has to collect keys and avoid obstacles to move onto the next level. In order to collect the key the player must solve a math problem to get the key. I've been tinkering with Kaboom by following YouTube videos and the Kaboom website. Some things I learned was how to create a map and make my character move.
